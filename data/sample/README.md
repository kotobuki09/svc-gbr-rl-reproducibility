# Synthetic demonstration sample

`svc_demo_synthetic.csv` contains 48 deterministic demonstration rows. It was
generated from the public release code and is not a random slice, redaction, or
anonymization of the operational SCADA records.

The `source_type` field must remain `synthetic_demo`. The `split_role` field is
for schema demonstration only; it must not be interpreted as an independent
paper evaluation split.
