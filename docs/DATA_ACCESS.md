# Request access to the complete data

## What is restricted?

The complete parent SCADA records, full augmented records, full evaluation
records, and row-level derivatives are not included in this public repository.
They may contain operationally sensitive information or may be subject to data
custody restrictions.

## Request route

Send a request to **[INSTITUTIONAL_DATA_CUSTODIAN_EMAIL]** with the subject
`SVC control data access request — [your name]`.

The final institutional contact will be inserted before the first public
release. This placeholder is intentional and is not a working address.

## Include these fields

- Name and institutional affiliation
- Research purpose and a short study protocol
- Exact files or data layers requested
- Storage and access-control plan
- Expected retention period
- Confirmation that the data will not be redistributed
- Preferred date for access and a contact person

## Review process

The data custodian may approve, approve with conditions, or decline a request.
Conditions may include a data-use agreement, secure storage, no onward sharing,
and deletion or return after the approved period. Access is not guaranteed and
the public synthetic sample is not a substitute for the restricted records.
