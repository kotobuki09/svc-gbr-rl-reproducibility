# Curated aggregate artifacts

This folder contains release-safe summary artifacts only. It does not contain
row-level training/evaluation data. A result is marked `author_confirmation_required`
when local working files disagree or the authoritative run has not been chosen.

`public_demo_features.csv` is the reproducible feature artifact generated from
the synthetic sample. The other CSVs are inspection-only snapshots until the
authoritative paper run is selected.

Do not use these tables to infer independent out-of-sample generalization.
